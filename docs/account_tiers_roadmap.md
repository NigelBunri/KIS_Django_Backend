# KIS Account Tiers — Feature Roadmap Checklist

This checklist tracks the tier features to implement over time. Use it to plan sprints and verify readiness.

## Phase 1 — Foundation (data + gates)
- [ ] Gate features by account tier in backend (tier features_json + flags).
- [ ] Add billing/upgrade audit log entries.
- [ ] Enforce tier limits for communities/groups/media.
- [ ] Show tier badges and feature lists in Profile > Upgrade.

## Phase 2 — Pro (creator tools)
- [ ] Higher media limits + HD uploads
- [ ] Enhanced profile visibility (rank boost)
- [ ] Advanced messaging tools (reactions, filters)
- [ ] Theme customization
- [ ] Extended history + faster sync

## Phase 3 — Business (KIS Business Broadcast)
- [ ] KIS Business broadcast channel under Broadcast tab
- [ ] Business profile with CTA buttons
- [ ] Business catalog (services/products)
- [ ] Offers + promo codes
- [ ] Auto-reply + business hours
- [ ] Audience insights (reach, CTR)

## Phase 4 — Business Pro (growth stack)
- [ ] Campaign scheduler + post boosting
- [ ] Advanced analytics (funnels, retention)
- [ ] Team roles + audit logs
- [ ] CRM-lite leads + export
- [ ] Priority moderation tools

## Phase 5 — Partner (organizations)
- [ ] Partner org with multiple sub-accounts
- [ ] Org-wide roles and permission scopes
- [ ] Live streaming + events
- [ ] Donations + revenue tools
- [ ] Partner dashboards (impact analytics)
- [ ] Priority support workflows
